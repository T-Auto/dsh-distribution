# @dsh-distribution/lodgement

Enumerable shared lodgement entries for the `discovery.distribution.dsh.dev/v1alpha1` protocol. **Draft / 0.1.0-alpha.1; not published.**

The package provides closed structural schemas and pure semantic helpers for duplicate identities, publication/removal, visibility, staged (not filesystem) atomic publication, ownership checks, and shared-carrier protection. It does not perform IO, polling, subscriptions, authentication, signatures, or persistent registry operations.

See [DIST-007 proposal](../../docs/proposals/lodgement.md) and the [conformance matrix](../../conformance/README.md).
